# Legacy audit 24,601–36,900

Source: `legacy/app/src/main/assets/index.html`. Range covers wallet groups, pair/swap-bot engine, AA paymaster, tx history, token manager + chain manager, full-screen token chart (SVG drawing engine + lightweight-charts), and WebSocket/REST market data. ## Security notes (values masked)

- 24617: plaintext wallet-group backup in localStorage — bypasses the AES path entirely.
- 27437: LI.FI API key hard-coded in JS (`b3e…`), shipped in the APK.
- 27846: Coinbase paymaster/bundler URL with embedded API key (`A6j…`) as the default.
- 28409/28431: Rango key in a query string (`_NEXUS_RANGO_KEY`, `e1f…`) — leaks via logs/referrers.
- 34337: CMC Pro key in `_API_KEYS.CMC_PRO` (`b1d…`).
- 24805 / 25508 / 25630: bulk private keys and mnemonics copied to the system clipboard, readable by other apps.
- 26438: Basescan placeholder key literal `YourApiKeyToken`.
- Contract import reads arbitrary user-supplied addresses over RPC with no allow-list; token metadata (name/symbol) is injected into `innerHTML` unescaped (36558–36572, 36784), an XSS vector via malicious token names.
