# Legacy audit 1–12,300

File: `legacy/app/src/main/assets/index.html` (single-file SPA "NEXUS — DeFi Terminal v2.5"). Range 1–12,300 is: bootstrap scripts → ~7,000 lines of CSS → body markup + per-feature inline `<script>` islands. Core app logic (wallet state, ethers signing, `br`/`SW` objects) starts beyond this range; here there are many forward references.

## Cross-range observations
- All state is localStorage; no cookie use. Keys in range: `nexus_console_log_enabled`, `nexus_bio_lock`, `nexus_lock_pin`, `nexus_lock_pat`, `nexus_bio_cred_id`, `__nexus_sw_code__`, `nexus_token_cache`, `nexus_token_cache_<last8>`, `nexus_active_chain`.
- Secrets: private keys live in plain `textarea`/`input type="text"` fields masked only by CSS (`-webkit-text-security: disc`, transparent `-webkit-text-fill-color`); a global `window.actualKeysStorage` object (referenced at 13184) holds unmasked key text. No secret values reproduced here.
- UX quirks: bridge quote auto-fires on amount input; balance pill is tap-to-refresh; recipient field deliberately suppresses the soft keyboard; the TX-progress overlay and the swap/send history dropdowns are dead code paths; every modal moves itself to `<body>` (11040) to escape `visibility:hidden` parents.
