# Legacy audit 86,101–98,580

Range = tail of `app/src/main/assets/index.html` (single-file WebView app, 98,579 lines). Contains the **Exchange (EXC)** module, the **Futures (FUT)** module, and three bottom-sheet modals: Exchange **Deposit**, Deposit **Token/Network** pickers, and Exchange **Withdraw**. One global native HTTP bridge is shared by all of them.

## Block 1 — 86,101–87,900 · EXC core, keys, markets
**State/keys:** `KEY_STORE='nexus_exc_keys_v1'` (86,239); `getKeys`/`saveKeys`/`getExchangeKey` (86,241–86,250). Despite a code comment mentioning AES/SubtleCrypto, keys are stored as **plaintext JSON** (apiKey, secret, passphrase, cdpKeyName, cdpPem).
**Functions:** per-exchange signed-fetch wrappers 86,266–86,668 (HMAC-SHA256/384/512 hex+b64, hand-rolled MD5, SHA-256/512 digests); `window._nxSignedFetch` (86,679); `fetchJsonWithFallback` (86,699); `fetchMarkets` (86,751); `_STATIC_MIN` (86,994) + `getTradeMinimums` (87,012); `preloadAllMarkets` (87,289, batches of **4**); `selectExchange` (87,429); `openApiSetup` (87,623); `saveApiKey` (87,729); `renderSavedKeys` (87,750, masks as `apiKey.slice(0,8)+'…'+slice(-4)`).
**Storage:** writes `nexus_exc_active`; reads `nexus_exc_pair_<excId>`; writes `nexus_exc_keys_v1`.
**Endpoints:** 15 exchanges — `api.binance.com`, `api.mexc.com`, `api.kucoin.com`, `api.bybit.com`, `api-cloud.bitmart.com`, `api.bitget.com`, `api.kraken.com`, `api.gateio.ws`, `api.exchange.coinbase.com`, `open-api.bingx.com`, `api.huobi.pro`, `api.phemex.com`, `openapi.digifinex.com`, `api.lbank.com`, `api.bitfinex.com`. Auth headers only: `X-MBX-APIKEY`, `X-MEXC-APIKEY`, `KC-API-KEY/-SIGN/-TIMESTAMP/-PASSPHRASE/-KEY-VERSION`, `X-BAPI-API-KEY/-SIGN/-TIMESTAMP/-RECV-WINDOW`, `X-BM-KEY/-SIGN/-TIMESTAMP`, `ACCESS-KEY/-SIGN/-TIMESTAMP/-PASSPHRASE`, `KEY`/`SIGN`/`Timestamp` (Gate), `CB-ACCESS-KEY/-SIGN/-TIMESTAMP/-PASSPHRASE`, `X-BX-APIKEY`, `API-Key`/`API-Sign`, `bfx-nonce`/`bfx-apikey`/`bfx-signature`.
`openApiSetup` calls `https://api.ipify.org?format=json` and shows the device's public IP (the point of the native bridge: the device IP, not the page origin, signs the request).
**UI:** key-entry fields for API key / secret / passphrase / Coinbase CDP key name + PEM; saved-key list with masked key.

## Cross-cutting
**Storage keys:** `nexus_exc_keys_v1`, `nexus_exc_active`, `nexus_exc_pair_<excId>`, `fut_lev_<excId>_<symbol>`.
**Bridge:** `window.nxFetch`, `window.nxBridgeGet`, `window.nxPost`, `NexusBridge.httpPost` — all signed traffic routes through the native layer; plain `fetch` with `AbortSignal.timeout` is the fallback.
**Security findings:** (1) API secrets/passphrases stored unencrypted in localStorage and readable by any page in the WebView; (2) DigiFinex auth = `SHA256(apiKey+ts+secret)` hex — reverses the usual "never send the secret" rule and is replayable within a 1 s bucket; (3) LBank embeds `api_key` in the signed body (form POST); (4) Coinbase PEM private key (`cdpPem`) also stored in the same plaintext blob; (5) withdrawal address is free-typed with only a length>10 check — no checksum/network validation.
**Quirks:** duplicate identical `excId === 'bitmart'` branches in `_wdBalance` (97,217 and 97,233) — first one calls `_hmac256` from another IIFE (ReferenceError, uncaught), so BitMart balance silently throws; the amount-input inline handler reads `window._wdStateFee` which is never assigned (fee always 0 in that calculation); `_wdState.addr` in withdraw state is set once but never used; deposit falls back to the connected wallet address only when no exchange is active.
